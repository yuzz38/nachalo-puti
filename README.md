# Начало пути — лендинг магазина для малышей и будущих мам (Красноярск)

Одностраничный сайт для магазинов «Начало пути» (Instagram: nachalo_puti.store): товары для детей от 0 до 5 лет и будущих мам, сумка в роддом, комплекты на выписку. Два филиала — Парусная, 3 и Партизана Железняка, 48д.

## Структура

```
index.html          — страница (9 блоков + шапка и подвал)
css/style.css       — стили, адаптив 320–1920 px
js/main.js          — интерактив без библиотек
img/                — оптимизированные изображения (WebP + JPEG, 2 размера), иконки
favicon.ico, site.webmanifest
robots.txt, sitemap.xml          — SEO
llms.txt                          — GEO: справка о магазине для ИИ-поисковиков
humans.txt, .htaccess, 404.html
```

## Блоки

1. **Hero** — слоган со стены магазина «Давай начнём эту историю вместе», фото в форме воздушного шара.
2. **Маршрут** — путь от беременности до 5 лет; линия прорисовывается при скролле.
3. **Магазин изнутри** — доска с фото и фишками: кресло для пап, пеленальный стол, детский уголок, консультанты.
4. **Сумка в роддом** — интерактивный чек-лист, сумка «наполняется» по мере отметок (сохраняется в браузере).
5. **Подарок** — выбор повода и бюджета, готовый текст запроса копируется в один клик.
6. **Сейчас на полках** — флис, комплект «Дино», BabyWell.
7. **Доставка** — условия по городу и России.
8. **Отзывы** — слайдер (свайп, стрелки, точки, клавиатура, перетаскивание мышью), отзывы из 2ГИС.
9. **Адреса** — переключение филиалов, карта Яндекса подгружается лениво, ссылка на маршрут в 2ГИС.

На десктопе ≥1360 px слева «высотомер» — навигация по блокам с воздушным шаром. На мобильных: бургер-меню на весь экран и плавающая кнопка звонка.

## Технически

- Чистые HTML/CSS/JS, без сборки и зависимостей; шрифты — Google Fonts (Pacifico, Unbounded, Manrope, Marck Script, все с кириллицей).
- Кроссбраузерно: вендорные префиксы для Safari/iOS, фолбэки для старых браузеров, safe-area iPhone, нативный свайп слайдера на Android и iOS, учитывается `prefers-reduced-motion`.
- SEO: title/description, canonical, Open Graph, Schema.org (Organization + 2 × ChildrensStore + FAQPage), sitemap с картинками.
- GEO: meta geo.region/placename, `llms.txt`, robots.txt, открытый для ИИ-краулеров.

## Перед публикацией

1. Замените домен `https://nachaloputi.ru/` на реальный в `index.html`, `robots.txt`, `sitemap.xml`.
2. При желании добавьте точные координаты филиалов (`geo` в Schema.org, meta `geo.position`).
3. Залейте содержимое папки в корень хостинга (Apache подхватит `.htaccess`).
